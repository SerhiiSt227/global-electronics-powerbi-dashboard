# Global Electronics Retailer: дашборд продажів (Power BI)

Навчальний проєкт (DAN.IT Data Analytics, частина Power BI фінального проєкту): багатосторінковий інтерактивний дашборд продажів глобального рітейлера електроніки.

**Дані:** [Global Electronics Retailer (Maven Analytics)](https://mavenanalytics.io/data-playground/global-electronics-retailer) — продажі, клієнти, товари, магазини, курси валют. Навчальний датасет із вигаданою компанією.

**Файл дашборду:** [`Global_Electronics_Dashboard.pbix`](Global_Electronics_Dashboard.pbix) — відкривається в безкоштовному Power BI Desktop.

## На які питання відповідає дашборд
1. Які види продукції реалізує компанія і де знаходяться клієнти? — сторінки *Products Analysis* та *Geography*
2. Чи є сезонність або тенденції в обсягах замовлень і доході? — *Sales Overview*
3. Який середній час доставки і як він змінився з часом? — *Sales Overview*
4. Чи відрізняється середній чек (AOV) в онлайні та в магазинах? — *Online vs Store*

## Сторінки
| Сторінка          | Зміст                                                                                                       |
|-------------------|-------------------------------------------------------------------------------------------------------------|
| Home              | KPI (продажі, прибуток, замовлення, AOV), тренд продажів 2016–2021, навігація                               |
| Sales Overview    | Тренди по роках і місяцях, топ категорій, продажі за віковими групами, час доставки, накопичувальні продажі |
| Products Analysis | Частка продажів за ціновими групами, топ товарів, продажі за категоріями, динаміка категорій (топ-5)        |
| Online vs Store   | Порівняння каналів: продажі, AOV за категоріями, тренд, вибір KPI перемикачем                               |
| Geography         | Топ країн, продажі за континентами, карта                                                                   |

## Модель даних
Зіркоподібна схема (star schema): факт-таблиця `FactSales` та довідники `DimCustomers`, `DimProducts`, `DimCategory`/`DimSubcategory`, `DimStores`, `DimCalendar`, `DimExchangeRates`.

DAX-міри: AOV, MoM/YoY, накопичувальні продажі (running total), середній час доставки.

## Принципи візуалізації
- у легендах не більше 4–6 елементів (на графіку категорій у часі залишено топ-5 через фільтр Top N)



## Технології
Power BI, DAX, Power Query, зіркоподібна модель даних.
